# Python Practice Repository

This repository is designed to mirror the structure of a previous Java training repository. It serves as a working directory to practice translating Java concepts and exercises into Python.

## Structure

The primary focus right now is in the `py-training` directory, which covers core Python basics translated from "Module 1" of the Java curriculum.

To map correctly, some Java specific topics such as "Inheritance and Abstract Classes" have been merged or pruned in favor of more idiomatic Python concepts, such as Duck Typing and the `abc` module.

### Setup
Ensure you have Python 3.x installed.
This repository uses `pytest` for unit testing. Install it via:
```bash
pip install pytest
```

You can run all tests linearly by navigating into each topic's subfolder and running `pytest`.
